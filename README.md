# Sueño Del Mar Surf School

This is the project for Sueño Del Mar Surf School, located in Morocco.

## Project Structure

- `index.html`: Home page
- `pages/`: Internal pages (Contact, Experiences, Legal)
- `assets/`: Static assets (CSS, JS, Images, Videos)
- `robots.txt` & `sitemap.xml`: SEO configuration

## Technologies

- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts
